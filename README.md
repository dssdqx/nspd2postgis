# nspd2postgis

Инструмент для автоматической загрузки, парсинга и импорта пространственных данных из Национальной системы пространственных данных (НСПД Росреестра) в СУБД PostgreSQL / PostGIS.

Проект предназначен для выгрузки векторных слоев НСПД (границы, участки ЕГРН, ОКС, ЗОУИТ) по пространственным контурам с автоматическим приведением атрибутов и геометрии к целевой схеме базы данных.

---

## 🛠 Возможности

- **Пакетная выгрузка**: забор векторных объектов НСПД в пределах заданного пространственного контура (область, район).
- **Маппинг и валидация атрибутов**: автоматическая обработка «легких» контурных объектов API, раскладка вложенных структуры `options` и затыкание отсутствующих полей (`NULL`).
- **Корректная работа с геометрией**: привод к EPSG:4326, автоматическое преобразование типов и поддержка пространственных индексов (`GiST`).
- **Кэширование**: поддержка локального файлового кэша запросов (`pynspd`) для предотвращения повторных сетевых вызовов.
- **Безопасный импорт**: работы через транзакции `psycopg` (v3) с корректным приведением JSONB-полей и обработкой конфликтов первичных ключей.

---

## 📂 Структура модулей

Репозиторий развивается как универсальный ETL-пайплайн для различных типов объектов НСПД:

| Скрипт / Модуль | Слой НСПД | Назначение |
| :--- | :--- | :--- |
| `get_nspd_brd_nas_punkt_to_postgis.py` | *Населённые пункты (полигоны)* | Экспорт полигональных границ населенных пунктов региона в слой `boundaries.nas_poly_nspd`. |
| `get_nspd_parcels_to_postgis.py` *(в разработке)* | *Земельные участки из ЕГРН* | Парсинг и загрузка полных атрибутов кадастровых участков (кадастровый номер, стоимость, категория, вид использования). |
